①

API 키가 필요한 이유

Gemini API의 역할: 채용공고 캡처 이미지를 등록했을 때, 이미지 속 텍스트(주요 업무, 지원 자격, 우대 사항)를 컴퓨터가 자동으로 읽어와 입력칸에 채워주는 시각 OCR 추출 기능에 Google Gemini API가 사용됩니다.

💡
API 키 없이도 즉시 사용 가능!
채용공고 텍스트를 직접 입력하거나 복사-붙여넣기 하시는 경우, API 키가 전혀 필요 없으며 비용 0원으로 16개 항목 기업분석 프롬프트를 바로 완성할 수 있습니다.
②

Google AI Studio 무료 API 키 발급 절차

Google 공식 개발자 콘솔에서 1분 만에 무료로 발급받으실 수 있습니다 (비용 0원, 신용카드 등록 불필요).

  1. Google AI Studio 공식 키 발급 페이지 ↗에 접속 후 구글 계정으로 로그인합니다.
  2. 화면 좌측 상단 또는 중앙의 파란색 [Get API key] (또는 [API 키 만들기]) 버튼을 클릭합니다.
  3. 팝업창에서 [Create API key in new project] (새 프로젝트에서 키 만들기) 버튼을 클릭합니다. (약 3~5초 소요)
  4. 생성된 키 목록에서 AIza...로 시작하는 키 우측의 [복사(Copy)] 아이콘을 눌러 클립보드에 복사합니다.
③

키 입력과 모델 선택 & 안전한 보관

  • 키 입력: 복사한 키를 상단 Gemini API Key 입력창에 붙여넣기(Ctrl+V)합니다.
  • 키 저장: [저장] 버튼을 누르면 브라우저 로컬 저장소에 보관되어 재방문 시 자동 입력됩니다. 저장 시 현재 브라우저에 저장됨으로 정확히 표시됩니다.
  • 키 삭제: [삭제] 버튼을 누르면 브라우저 저장소에서 즉시 영구 삭제되며 '미저장' 상태로 전환됩니다.
  • 추천 모델: 기본값인 3.6 Flash(최신 권장)를 사용하시면 가장 빠르고 정확하게 분석됩니다. 빠른 속도는 3.5 Flash-Lite, 복합 추론은 3.1 Pro를 지원합니다.
④

연결 상태 확인 (4단계 라이프사이클)

상단의 [⚡ 연결 테스트] 버튼을 누르면 API 키와 모델의 유효성을 0.5초 만에 진단합니다.

⚪ 미확인: 아직 테스트하지 않았거나 키/모델이 변경된 상태
🔵 확인 중: Google 서버와 신호를 주고받는 중
🟢 연결 성공: 단순 텍스트 통신 성공 (키 및 모델 정상)
🔴 연결 실패: 키 오류(400), 모델 만료(404), 할당량 초과(429) 등

※ 키나 지정 모델을 변경하면 기존 연결 상태는 자동으로 미확인으로 초기화됩니다.
※ 텍스트 연결 테스트 성공과 실제 캡처 이미지 추출 성공은 결과 배지에 각각 명확히 구분되어 표시됩니다.
